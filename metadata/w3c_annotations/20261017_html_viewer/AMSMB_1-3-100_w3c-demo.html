Medieval charter AMSMB_1-3-100 — 24 text lines as W3C Web Annotations

This experiment builds on Noemi's testsvg2.html. The W3C annotations are embedded in this page, and each SvgSelector is drawn over the image. Here we test two ways to include the baselines. Click any line, baseline or zone to see its annotation.

Version A. W3C has no concept of a baseline, so we link it. Each annotation has a link (XPath) to its element in the PageXML, and the lines also have their transcription. The baselines stay in the XML, so they are not drawn here. This version is the output of our PageXML → W3C converter.

Version B. Noemi suggested to also have the baselines as W3C annotations. We keep everything from version A and add one annotation per baseline, with its coordinates as an SVG polyline (red lines). Lines, zones and baselines are also typed against the PAGE schema. This way, the baselines can be read without the XML.

Known issues and things to improve

  
This page is kept as a record of the experiment, so these issues are still present in its annotations.

  
    
    
  • Missing region: eSc_textblock_9efc09ad (at 53,65 to 160,203) has no annotation, so version A has 33 annotations for 34 elements. It is the only untyped region, so the converter probably skips untyped regions, although it keeps untyped lines.
    • 
    
  • Baseline motivation: the agreed mapping says identifying, but version B uses classifying. This still needs a decision.
    • 
    
  • Image size: width and height are not defined in the W3C anno.jsonld context, so JSON-LD processing drops them.
    • 
    
  • SVG namespace: polygons use <svg> without xmlns, but baselines include it. This page rebuilds the shapes to work around that, and strict SVG parsers may reject them.
    • 
    
  • Schema link: in version B, the TextRegion XPath matches 2 elements in the PAGE XSD. TextLine and Baseline match 1 each.
    • 
    
  • Creators: region annotations have no creator. Baselines credit the transcriber's ORCID, but the datasheet does not say who drew them.
    • 
    
  • Rights and language: the annotations have no rights or language.
    • 
    
  • Dataverse links: datafile/821 and datafile/889 have not been confirmed to point to this charter's files.
