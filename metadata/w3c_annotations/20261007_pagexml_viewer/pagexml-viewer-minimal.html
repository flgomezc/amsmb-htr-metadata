PageXML → W3C Web Annotations

Minimal version of pagexml-viewer.html, written 2026-11-05: same mapping, nothing embedded. Choose a charter's JPEG and its PageXML together. The shapes are drawn from the W3C JSON-LD below.

Output structure

AnnotationPage            id: …#AnnotationPage_<charter>
└─ items
   ├─ Annotation (zone)   motivation: classifying
   │   ├─ body:   tag (SegmOnto type) + link to the TextRegion in the PageXML
   │   └─ target: image + polygon (SvgSelector) + bounding box (FragmentSelector)
   └─ Annotation (line)   motivation: describing, creator, generator
       ├─ body:   transcription + tag (SegmOnto type, if any) + link to the TextLine in the PageXML
       └─ target: image + polygon (SvgSelector) + bounding box (FragmentSelector)

Every target is the image, with the shape as an SvgSelector polygon and its bounding box as a FragmentSelector.

Known issues

  • No baselines: they stay in the PageXML, behind the linking XPath.
  • Untyped regions are skipped, as with eSc_textblock_9efc09ad.
  • SVG selectors have no xmlns.
  • width and height are dropped in JSON-LD processing.
  • Links are file names, not Dataverse URLs.
