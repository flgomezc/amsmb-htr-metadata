# README.md

This repo contains the metadata for the AMSMB dataset "A Dataset for Handwritten Text Recognition in Medieval Notarial Charters Written on Parchment". 

The original dataset is published at BSC-Dataverse, we have here just a couple of images and their transcriptions.

Metadata will be prepared to make this dataset machine actionable. We are preparing this metadata following the DDI-CDI and Croissant.

For DDI-CDI we test the W3C annotations, to include the xml annotations in a supported DDI-CDI format.
